# ペット健康カルテ

ペットの健康診断、ワクチン、通院、投薬、体重を端末内に記録する PWA です。獣医さん向けのカルテ表示、印刷・PDF保存、テキストコピーができます。

## 起動

このフォルダで次を実行し、`http://localhost:8080` を開きます。

```sh
python3 -m http.server 8080
```

スマートフォンでは HTTPS で配信した URL を開くとホーム画面に追加できます。Service Worker と IndexedDB は HTTPS または localhost で動作します。初回のアプリ読み込みには通信が必要です。写真の文字読み取りには外部 CDN と言語データへの通信が必要ですが、オフラインでも写真添付・手入力・保存は使えます。

## 公開URLで使う

GitHub Pages の公開URL（`https://<user>.github.io/pet-karte/`）をスマホで開き、ブラウザの共有メニューから「ホーム画面に追加」を選びます。データはスマホの中だけに保存されます。機種変更前には設定画面からバックアップを書き出してください。

## 主な機能

- 複数ペットの登録、健康記録、写真添付、次回予定のお知らせ
- 写真からの文字読み取り候補と、保存前の手動確認
- 体重グラフ、獣医さん向けカルテ、印刷・PDF保存、テキストコピー
- 写真を含む JSON バックアップの書き出し・読み込み

データはブラウザの IndexedDB に保存します。ログインやクラウド同期はありません。端末の紛失・ブラウザデータ削除に備えて、設定から定期的にバックアップを保存してください。バックアップファイルには連絡先や医療情報、写真が含まれます。
